# Publication Record

## Born-Agentic Organization Concept Draft v0.1

**Initial public repository version: 2026-09-11**

This repository publicly documents the integrated Role-first **Born-Agentic Organization** model described here, in which:

1. Roles may exist before employees.
2. A persistent Role Agent may work before a Human is assigned.
3. The Role — rather than the Employee or the Model — is the persistent organizational unit.
4. A Role can detect a Capability Gap.
5. A Role can initiate a request for Human capability (Machine-Initiated Hiring).
6. A People Agent can source and coordinate candidates.
7. The Role Agent can participate in role-specific assessment.
8. A Human is attached through an Assignment object.
9. Organizational memory persists through Human turnover (Active Organizational Memory).
10. Workforce planning can shift from headcount planning toward Capability Allocation.

# Contributing

This repository currently focuses on the conceptual model and reference architecture.

Useful contribution areas include:
- Role modeling
- organizational memory
- multi-agent coordination
- durable execution
- human-agent assignment
- capability measurement
- authorization
- governance
- recruiting workflows
- empirical validation

Please distinguish clearly between existing prior art, proposed extensions and experimental implementation ideas. See [NOTICE.md](NOTICE.md) for the scope statement.

Terminology is fixed across this repository so that the model stays machine-readable and unambiguous. If you introduce a concept, use the canonical terms — **Born-Agentic Organization**, **Role-first**, **Role Agent**, **Capability Gap**, **Machine-Initiated Hiring**, **Human Assignment**, **Active Organizational Memory**, **Capability Allocation** — or add the new term to the terminology table in [README.md](README.md).
